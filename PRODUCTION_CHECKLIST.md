# Checklist production

- [ ] `npm run verify` thành công.
- [ ] GitHub Actions xanh.
- [ ] Hai biến Supabase có trong Vercel Production/Preview/Development.
- [ ] Không commit `.env.local`.
- [ ] Supabase Site URL là URL production.
- [ ] Redirect URL localhost và production đã được cho phép.
- [ ] Đăng ký, xác nhận email, đăng nhập hoạt động.
- [ ] Quên mật khẩu và đổi mật khẩu hoạt động.
- [ ] Làm bài, lịch sử, bài đang làm dở đồng bộ giữa hai thiết bị.
- [ ] `health.json` trả status ok.
- [ ] Giao diện điện thoại không bị tràn ngang.
- [ ] Có thể thêm website vào màn hình chính.
- [ ] Tải lại trang không báo 404.
- [ ] Kiểm tra chính sách RLS bằng hai tài khoản khác nhau.
